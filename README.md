# DSHIO 标准体系

**DSH（DeepSeek Harness）插件的第三方标准。**

本仓库是 DSHIO 标准的源文件仓库。标准的网页版在 **https://dshio.org**。

---

## 这是什么

DSHIO 是一套针对 DSH 插件的第三方标准，由 DSHIO 独立编写与维护。

**不是 DeepSeek 官方规范。** 标准从官方开发套件的实际行为归纳而来，但：

- 不要求使用官方开发套件
- 不要求特定编程语言、构建工具或依赖
- 判定以可观测的运行时行为为准，不以源码结构为准

任何人按标准写出的插件都是合格的 —— 不论他怎么实现。

| 测试阶段 | 名称 | 状态 |
|---|---|---|

| T1 | 安装 | ✅ 已提供 |

**T5 为何待规划：** 涉及模型成本与随机性（见 DSHIO/T 32 第 4.3 条）。

**人工判断条款（5.5.1、5.5.2）由开发者自行判定。**
DSHIO 不出具这两条判定结论；如需出具意见，属付费服务。

## 认证状态

**DSHIO 当前出具「检验报告」，不出具「认证证书」。**

| 产出 | 是否提供 | 说明 |
|---|---|---|
| 检验报告 | ✅ 提供 | 覆盖 T0–T4，含环境指纹、重复性、总体判定 |
| 认证证书 | ❌ 不提供 | DSHIO/T 32 整体仍为「试行 · 未启用」 |
| L3 级别 | 🕐 待规划 | 需要 T5 |

**获得检验报告不等于获得认证。任何把检验报告说成认证的表述均为虚假。**

## 怎么引用

```
DSHIO/T 10—2026 第 5.2.2 条
```

**不要写：**
- `DSHIO-DEV`（已废止的旧代号）
- `DSHIO 插件标准第 2 条`（必须带标准号）
